# 1. Adaptive Single-Line Statusline

We decided to implement a single-line custom statusline that dynamically hides less critical segments (credits, VCS branch, and execution state) based on the terminal width, rather than using multi-line wrapping. This keeps the layout compact and compatible with the single-row status bar allocated by the Antigravity TUI.

Key design decisions:
- **Dynamic Multi-Quota Discovery & Active-First Cluster** (amended 2026-10, supersedes Dual-Quota Display): Discover quota buckets dynamically from `.quota` map (`<family>-5h`, `<family>-weekly`, e.g. `gemini`, `3p`, `argon`) so new model buckets appear/retire automatically. Match active model via specific-word match against `.model.display_name` (plus 3rd-party model family → `3p` alias, displayed as `Other` / `Oth`). Render unified quota cluster with active family first (`▸Active: Pct% ▰▰▰▰▱ (timer) · Standby: Pct% (timer)`), preserving compact reset timers (`3d12h`, `4h50m`) across all families. Family = bucket key minus window suffix, minus leading `gemini-[<ver>-]` when sub-model follows (`gemini-argon-weekly` → `argon`). Standby order: `argon` → `gemini` → `3p` (`Other`) → others alphabetical. Active sub-model without own bucket falls back to `gemini`.
- **Active Model 5-Cell Pill Gauge & Dual-Window Surfacing** (amended 2026-10): Active model quota features a high-visibility 5-cell pill progress bar (`▰▰▰▰▱`) indicating remaining capacity. For dual-window models (e.g. Gemini sprint + weekly), active model surfaces sprint and weekly via a muted diagonal slash (`▸Gemini: 90% ▰▰▰▰▰ (4h50m) ╱ 82%wk (3d)`). Standby models display only their 5-hour window by default; weekly is surfaced only if exhausted or almost exhausted (<20%). Timers are styled in muted soft gray (`\033[38;5;244m`) with `⚡` splurge cue (<24h with ≥20% unused) and `⚠` run-out risk cue.
- **Context Window 1-Decimal Precision & 10-Cell Solid Bar** (amended 2026-10): Render precise 1-decimal capacity percentage derived from `.context_window.used_percentage` and a dedicated 10-cell solid progress bar (`Ctx: 52.0% █████░░░░░ ⚠`); omit confusing session-cumulative raw token numbers. Under width constraints, the 10-cell progress bar drops first to preserve compact text `Ctx: 52.0% ⚠`.
- **Aesthetic Refinements & State Glyphs** (amended 2026-10): Muted vertical rule separators (`│` in `\033[38;5;238m`); `✦ ` model symbol; standardized state icons (`● IDLE`, `◐ THINKING`, `⚙ WORKING`, `⏸ WAITING`); widened project name limit to 16 chars.
- **Progressive Degradation Truncation Cascade** (amended 2026-10): When exceeding terminal width, compress in order: (1) drop context token count (`Ctx: 52%`), (2) abbreviate standby names (`Gem:`, `Oth:`), (3) drop active quota 5-cell pill bar, (4) fold non-critical standby weekly sub-windows, (5) drop healthy standby timers, (6) drop standby quotas completely, (7) drop VCS segment, (8) drop context segment.
- **Unicode-only rendering** (amended 2026-08): Single foreground Unicode glyph set; nerd-font/ascii presets removed to reduce maintenance. Users needing ASCII-only terminals rely on width truncation and abbreviated segments.
