# 1. Adaptive Single-Line Statusline

We decided to implement a single-line custom statusline that dynamically hides less critical segments (credits, VCS branch, and execution state) based on the terminal width, rather than using multi-line wrapping. This keeps the layout compact and compatible with the single-row status bar allocated by the Antigravity TUI.

Key design decisions:
- **Dynamic Multi-Quota Discovery & Active-First Cluster** (amended 2026-10, supersedes Dual-Quota Display): Discover quota buckets dynamically from `.quota` map (`<family>-5h`, `<family>-weekly`, e.g. `gemini`, `3p`, `argon`) so new model buckets appear/retire automatically. Match active model via specific-word match against `.model.display_name` (plus 3rd-party model family → `3p` alias). Render unified quota cluster with active family first (`▸Active: Pct% (timer) · Standby: Pct% (timer)`), preserving compact reset timers (`3d12h`, `4h50m`) across all families.
- **Pace-Aware & Use-It-Or-Lose-It Weekly Surfacing** (added 2026-10): Compare weekly `remaining_fraction` against remaining week fraction (`reset_in_seconds / 604800`). Color weekly quota yellow when Over-Pace (`Quota% < WeekLeft%` or `<50%`), red when `<20%` or exhausted. For dual-window families (`gemini`, `3p`), surface `/ Weekly% (timer)` alongside 5h Sprint Quota when family is active, Over-Pace/`<50%` (run-out risk), or resetting in `<24h` with `>20%` unused (use-it-or-lose-it splurge window).
- **Context Rot Display** (amended 2026-10): Render total active tokens, capacity percentage, 10-cell progress bar, and Context Rot warning (`Ctx: 48.3k · 52% [█████░░░░░] ⚠`); omit `(in↓/out↑)` token split to free horizontal budget for multi-model quotas.
- **Timer-Preserving Truncation Cascade** (amended 2026-10): When exceeding terminal width, compress in order: (1) drop Context 10-cell bar, (2) abbreviate model/family names and drop Context token count, (3) fold non-critical standby weekly sub-windows, (4) drop healthy standby reset timers, (5) drop standby quotas, (6) drop VCS segment.
- **Unicode-only rendering** (amended 2026-08): Single foreground Unicode glyph set; nerd-font/ascii presets removed to reduce maintenance. Users needing ASCII-only terminals rely on width truncation and abbreviated segments.
